Infrastruktur MikroTik & WinBox Lab

SMK Budhi Warman 1 TKJ RouterOS v7

Uraian Studi Kasus:

Proyek ini merepresentasikan perancangan dan implementasi infrastruktur jaringan laboratorium komputer SMK Budhi Warman 1. Tristan melakukan segmentasi subnet IP menggunakan WinBox dan Command Line Interface (CLI), mengonfigurasi Network Address Translation (NAT masq), DHCP Server multi-pool, dan manajemen lalu lintas data.

Fitur Teknis yang Diterapkan:

  • Firewall Filter Rules untuk memblokir port yang tidak aman dan proteksi DDoS dasar.
  • Simple Queues & Queue Tree untuk membatasi kuota unduh/unggah tiap segmen client.
  • Static & Dynamic DNS Cache untuk akselerasi akses browsing lokal laboratorium.
